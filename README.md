# Lume Mail

Assistente local de e-mail para Windows — piloto experimental.

[Site](https://lume-mail.cloud-ip.cc/) · [Privacidade](https://lume-mail.cloud-ip.cc/privacidade) · [Termos](https://lume-mail.cloud-ip.cc/termos)

## Distribuição

Este repositório é exclusivo para instaladores, instruções e licenças de terceiros. Não contém código privado, credenciais OAuth, tokens nem mensagens de usuários.

**[Baixar o piloto 0.5 gratuito](https://github.com/Clarki7/lume-mail-downloads/releases/tag/v0.5.0-pilot)** — instalador, instruções e licenças. Versão experimental, sem liberação comercial. Comece pelos exemplos fictícios e não habilite envio.

## O que o piloto faz

- Consulta o Gmail após consentimento no Google; não pede a senha no aplicativo.
- Classifica trechos de mensagens por regras explicáveis.
- Gera sugestões de texto com IA local.
- Permite pausar a rotina e revisar as sugestões.

## Limitações importantes

- A marca foi verificada no Google; a aprovação do escopo Gmail de leitura continua pendente.
- O desempenho em computador físico Intel com 4 GB ainda precisa ser validado.
- O executável não tem assinatura digital, atualizador ou desinstalador nativo.
- A configuração OAuth de novos usuários ainda exige uma etapa manual.
- IA e triagem podem errar. Não use sugestões sem revisão humana.
- Não desative antivírus ou proteções do Windows para instalar.

## Segurança

Nunca publique senhas, tokens, mensagens, arquivos de cliente OAuth ou documentos pessoais nas issues. Use apenas exemplos fictícios para relatar problemas.
