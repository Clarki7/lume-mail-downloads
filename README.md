## 📦 Distribuição

Este repositório é exclusivo para instaladores, instruções e licenças de terceiros. Não contém código privado, credenciais OAuth, tokens nem mensagens de usuários.

O pacote do piloto traz o instalador, as instruções e as licenças. É uma versão experimental, sem liberação comercial. Comece pelos exemplos fictícios e não habilite o envio.

## ✨ O que o piloto faz

- 🔐 Consulta o Gmail depois do seu consentimento no Google, sem pedir a senha no aplicativo
- 🗂️ Classifica trechos de mensagens por regras explicáveis
- 🤖 Gera sugestões de texto com IA local
- ⏸️ Permite pausar a rotina e revisar as sugestões

## ⚠️ Limitações importantes

- A marca foi verificada no Google; a aprovação do escopo Gmail de leitura continua pendente.
- O desempenho em computador físico Intel com 4 GB ainda precisa ser validado.
- O executável não tem assinatura digital, atualizador ou desinstalador nativo.
- A configuração OAuth de novos usuários ainda exige uma etapa manual.
- IA e triagem podem errar. Não use sugestões sem revisão humana.
- Não desative antivírus ou proteções do Windows para instalar.

## 🐞 Como relatar um problema

Use o [formulário de problema](https://github.com/Clarki7/lume-mail-downloads/issues/new/choose). Ele já pede as informações certas: versão, Windows e passos para reproduzir.

## 🔒 Segurança

Nunca publique senhas, tokens, mensagens, arquivos de cliente OAuth ou documentos pessoais nas issues. Use apenas exemplos fictícios para relatar problemas. Falhas de segurança devem ser reportadas em particular, conforme a [política de segurança](SECURITY.md).

## 📜 Licenças

Cada componente de terceiros mantém sua própria licença. Nenhuma licença de código aberto é concedida implicitamente ao aplicativo por este repositório. Os avisos de redistribuição devem acompanhar cada versão.
